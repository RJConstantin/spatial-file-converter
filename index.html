Spatial Data Utility

Shapefile Converter

Convert shapefiles, KML, KMZ and GPX files between formats. Choose which attribute fields are kept and which field is used for feature names in GPX and KML output.

Files are processed in your browser and are not uploaded to a server.

1. Add a spatial file

For a shapefile, upload a ZIP containing the shapefile components or select the SHP, DBF, SHX, PRJ and related files together. KML, KMZ and GPX can be uploaded directly.

No spatial file loaded.

2. Choose the fields to keep

All attribute fields are selected by default. Geometry is always retained. Shapefile output uses the DBF 10 character field name limit.

3. Choose the output

KML and GPX coordinates are WGS 84. When creating a shapefile, the geometry is transformed to the coordinate system selected here and the matching PRJ is included.

Not sure which coordinate system to choose?

First, look at the coordinate numbers.

Looks like: -113.5, 56.7 These are longitude / latitude values. Use WGS 84 latitude / longitude or NAD 1983 latitude / longitude if that is the system you need to match.
Looks like: 473566, 6362909 These are metre-based coordinates. If you are matching an existing dataset, check whether its source says UTM, 10TM or 3TM.

For a typical Alberta UTM output:

  • Western Alberta: Calgary, Slave Lake, Grande Prairie, Hinton and Jasper are generally NAD 1983 UTM Zone 11N.
  • Eastern Alberta: Edmonton, Fort McMurray, Fort McKay and Cold Lake are generally NAD 1983 UTM Zone 12N.

Use the source name when it is provided. If the required system specifically says 10TM / AEP Forest, select NAD 1983 10TM AEP Forest. If it says 3TM, select the matching 3TM option.
